6/8/2026 - Axiomatização dos Números Naturais
- Na figura temos grafos direcionados (digrafos) e, em seguida, conjuntos de afirmações. Os pontos de cada digrafo representam os elementos de um conjunto N e as setas representam a lei de associação de uma relação s de N em N. Para cada conjunto de afirmações, identifique os digrafos que verificam todas as afirmações do conjunto (como fizemos em sala).


(A) A relação s é uma função. A relação s não é injetiva. Todos os pontos recebem seta (isto é, a relação s é sobrejetiva). Um ponto recebe uma seta dele mesmo (isto é, um elemento de N é a imagem dele mesmo pela função s).
(B) A relação s é uma função. A relação s não é injetiva. A relação s não é sobrejetiva. Existe um único elemento a pertencente a N tal que s(a)=a. Existe um único elemento de N fora da imagem de s.
(C) A relação s é uma função. A relação s é sobrejetiva. Não existe um elemento de N que não seja imagem de algum elemento de N pela função s.
(D) A relação s é uma função. Existe um conjunto de pontos sem imagem relacionada. A relação s não é injetiva. A função é injetiva.
(E) Cada ponto está associado ao seguinte.
(F) A relação s é uma função. A relação s é injetiva. Existe um elemento de N que é a imagem de si mesmo pela função s.
(G) A relação s é uma função. A relação s não é injetiva. A relação s é sobrejetiva. Existe um único elemento de N fora da imagem de s. O grafo descreve uma função avaliada continuamente, isto é, tem início mas não tem fim.
(H) Qualquer ponto tem um único associado. Todo ponto está associado a outro. Um ponto não está associado a si mesmo. Dois pares de pontos relacionados só se relacionam uma única vez.
(I) A relação não é uma função. A relação s não é injetiva. Todos os pontos recebem seta (isto é, a relação s é sobrejetiva). Um ponto recebe uma seta dele mesmo (isto é, um elemento de N está associado a si mesmo pela relação s).
- Agora, para cada conjunto de afirmações, esboce um digrafo que verifique todas as afirmações do conjunto e que seja diferente de todos os digrafos apresentados na figura.
- (Opcional) Leia o texto: Ivan Niven, Números: Racionais e Irracionais, SBM/MAA, Rio de Janeiro, 1990 [Capítulo 1].
